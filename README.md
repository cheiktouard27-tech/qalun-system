# نظام إدارة معهد قالون لتحفيظ القرآن الكريم

نظام متكامل بخادم Flask وقاعدة بيانات SQLite حقيقية، وواجهة عربية RTL تعمل على الهاتف والحاسوب.


## الموقع العام (للاطلاع بدون تسجيل دخول)

المجلد `public-site/` يحوي موقع المعهد العام: تعريفاً بالبرامج والأسئلة الشائعة، وزر تواصل يفتح واتساب/البريد. **أي شخص يمكنه تصفحه.**

قبل الرفع عدّل ملف `public-site/index.html` في أعلى الصفحة (قسم `SITE_CONFIG`):
- `whatsapp` — رقم المعهد بكود الدولة (مثال: `22277123456`)
- `email` — بريد المعهد الحقيقي
- `portal` — رابط نظام الإدارة (بعد نشره على Render) ليظهر رابط «بوابة الموظفين»

### النشر المجاني — خياران:
**أ) Netlify Drop (الأسهل، بدون Git):**
1. ادخل `app.netlify.com/drop`
2. اسحب مجلد `public-site` وأفلته في الصفحة
3. خلال ثوانٍ تحصل على رابط عام (مثل `https://qalun-website.netlify.app`) — ويمكنك تسمية الرابط مجانًا.

**ب) GitHub Pages (من نفس مخزن Render):**
1. ارفع مجلد `public-site` في نفس مخزن `qalun-institute`.
2. من GitHub: **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`، Folder: `/public-site` → Save.
3. خلال دقيقة يظهر رابط مثل `https://اسمك.github.io/qalun-institute/public-site`.

## الحسابات التجريبية

- `admin` مدير (صلاحية كاملة) · `teacher` معلم · `agent` وكيل · `accountant` محاسب

**بعد النشر الأول — بالترتيب:**
1. ادخل كـ admin وغيّر كلمة المرور فورًا (قائمة المستخدم ← حسابي).
2. من «إعدادات المعهد»: نزّل نسخة احتياطية أولى (اختياري للتعرف على البيانات).
3. اضغط «مسح البيانات التجريبية وبدء العمل الفعلي» ليبدأ المعهد ببيانات نظيفة (أرقام الطلاب تبدأ من QL-0001).
4. أنشئ حسابات المعلمين والوكلاء من «الحسابات والصلاحيات» بأسماء حقيقية وكلمات مرور خاصة، ثم أضف الحلقات والطلاب.

## نشر النظام على الإنترنت

### الخيار الأول — Render (الأسرع، مجاني)
1. أنشئ حسابًا مجانيًا على GitHub.com، ثم أنشئ مخزنًا جديدًا (مثلاً `qalun-institute`).
2. ارفع ملفات هذا المجلد كاملًا إلى المخزن (app.py، requirements.txt، static/، render.yaml، Procfile، backup.sh).
3. ادخل render.com → **New → Web Service** → اربط المخزن.
4. عند السؤال عن الإعدادات تأكد: Build = `pip install -r requirements.txt`، Start = `gunicorn --bind 0.0.0.0:$PORT --workers 1 --threads 4 --timeout 60 app:app`.
5. اضغط **Deploy** وستحصل على رابط عام مثل `https://xxx.onrender.com`.

**تنبيهان مهمان للخيار المجاني:**
- الموقع يستيقض بعد ~30 ثانية من الخمول.
- القرص مؤقت: **تُمحى البيانات عند كل إعادة نشر**. لذلك نزّل نسخة احتياطية دوريًا (إعدادات المعهد → تنزيل نسخة احتياطية) واحتفظ بها، أو اربط «Disk» مدفوعًا (~7$/شهر) من لوحة Render ليصبح التخزين دائمًا.

### الخيار الثاني — PythonAnywhere (مجاني مع تخزين دائم)
1. حساب مجاني على pythonanywhere.com (اختر BETA).
2. أنشئ Web App ← Flask (Python 3) ← اربطه بمخزن GitHub أو انسخ الملفات.
3. في WSGI configuration ضع: `application = app` (من ملف app.py).
4. البيانات تُحفظ دائمًا في مجلد home، وأضف Cron job يوميًا ينفّذ `bash backup.sh`.

### الأمان قبل إدخال بيانات حقيقية
- HTTPS مفعّل تلقائيًا على الخيارات أعلاه (فعّل `COOKIE_SECURE=1` كمتغير بيئة إن أمكن).
- غيّر كل كلمات المرور التجريبية.
- نسخة احتياطية يومية + احتفاظ نسخة في مكان خارجي (بريدك / سحابة).

## الاختبارات والنسخ الاحتياطي
- `python test_system.py` — 14 اختبارًا (الصلاحيات، العزل، نقل الطلاب، المالية، الأرشيف).
- إدارة النسخ: من «إعدادات المعهد» → تنزيل نسخة احتياطية / استعادة من نسخة (تُنشئ تلقائيًا نسخة «قبل الاستعادة»).
- `./backup.sh` — نسخة موقّعة الزمان في مجلد backups (تُبقي آخر 14 نسخة).
- الاستعادة: انسخ ملف النسخة مكان `data/qalun.sqlite3` وأعد التشغيل.
